# House Q logo mark

This separate-project mark translates the supplied house-and-`Q` sketch into the same visual system as the selected BunkFy logo: bold equal-weight monoline geometry, rounded caps and joins, a white mark, and the `#084F39` primary-green field.

- `house-q-mark.svg` is the primary white-on-green presentation mark.
- `house-q-mark-mono.svg` is the transparent monochrome mark.
- `house-qs-mark.svg` merges the roof and `Q` into one continuous house outline, then adds an architectural `S` that follows the same roof-slope, alternating wall, and base geometry.
- `house-qs-mark-mono.svg` is its transparent monochrome companion.
- Canvas: `288 x 256`
- Stroke: `16`
- Field radius: `30`

The files are standalone and are not referenced by the BunkFy frontend.
