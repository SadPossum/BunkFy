# BunkFy brand mark

The mark refines the original hand-drawn idea into a wide geometric `B` that also reads as two stacked bunks. Every drawn element uses the same stroke weight. Repeated diagonal capsules sit close to the left wall and low in each opening so they read as pillows. A single soft fold near the foot of the top bunk suggests a blanket. A large handled suitcase and a smaller handleless case overlap and knock out part of the lower rail, adding a playful hospitality detail.

- `bunkfy-mark.svg` is the black-on-forest presentation mark.
- `bunkfy-mark-white.svg` is the white-on-forest presentation mark.
- `bunkfy-mark-white-simple.svg` is the simplified white candidate with one suitcase and no blanket.
- `bunkfy-mark-white-simple-bold.svg` is the higher-weight simplified candidate for matching the semibold wordmark.
- `bunkfy-mark-mono.svg` is the transparent single-color mark for flexible placement.
- Ink: `#0B0F0C`
- Forest: `#084F39` (the website primary token, `oklch(38% 0.075 166)`)
- White: `#FFFFFF`

Both files are transparent, use only vector paths, and remain editable at any size.
